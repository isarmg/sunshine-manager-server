# 新建 Sunshine 实例

1. 点击「新建实例」后立即以默认名称创建，随后可在详细信息页修改名称。
2. 页面以账户名、只读账户（设备内部 ID）和密码（授权码）展示配对信息。授权码属于该实例、没有有效期，由 Server 加密保存，并可查看或更换。
3. 在 Sunshine 主机按 Client 安装手册通过受保护输入提交 `authorization_code`。Sunshine 密码只留在 Client 本机。
4. Client 使用可信 HTTPS 注册并建立 WSS 通道。授权码不会因首次绑定而被消耗；运行连接仍使用独立设备凭据。
5. 更换授权码会在同一数据库事务中撤销旧设备凭据、终结尚未执行的旧任务，并将已领取但结果未确认的任务标为 `unknown` 等待人工核对。任务日志显示“实例授权码已更换”的状态原因；管理员应核对 `unknown` 任务的实际设备状态。实例随即恢复为待配对；停止 Client 服务，使用新码显式执行 `pair replace`，成功后重新启动服务。重新配对不会执行旧授权下排队的任务。

没有授权码有效期设置。未配对时仍可取消当前授权码；之后可更换授权码以恢复同一实例。

取消配对、授权码更换与注册在数据库事务中互斥。永久退役使用「撤销设备凭据」；普通重配对应使用「更换授权码」。Client 在线、Sunshine 可访问、配置生效状态仍分别展示。

Server 只接受当前数据库 Schema 和身份；启动不会清空或自动转换不匹配的数据。
