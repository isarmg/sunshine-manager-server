# xscs 1.0.1

## 自 1.0.0 以来的更新

- 保存 Sunshine 应用时保留稳定身份，并按接收时间排序设备观测。
- 重启 Sunshine 时使用已确认的配置修订，保留有效的已配对客户端显示名称。
- 服务状态与诊断结果区分过期观测，避免将旧结果显示为当前状态。
- 支持单主机部署的远程 HTTPS 入口，更新安装与运维指南。
- Rust 与内嵌管理 Web 同步采用已验证并锁定的 xcss 1.0.2。
- 软件与打包版本更新为 1.0.1；协议包及数据库身份保持 1.0.0。

## 下载与安装

平台：Linux x86_64 GNU。发行资产：`xscs-1.0.1-x86_64-unknown-linux-gnu.tar.gz` 和 `xscs-1.0.1-x86_64-unknown-linux-gnu.tar.gz.sha256`。

安装步骤见[部署指南](../operations.md)。
