# Sunshine Manager Server 0.11.8

- 在“详细信息 → 配置设置”顶部加入横向分类菜单，按概况、输入、音频/视频、网络、配置文件、高级及设备支持的编码器展示配置。
- 切换分类保留未提交编辑和恢复默认选项，变更预览汇总全部分类；无效输入会自动定位到对应分类。窄屏支持横向滚动。
- 配置本地前端开发服务与 API 代理，保留浏览器 Host，修复通过开发端口登录时的同源校验失败。
- 包含主分支已有的 Foundation 0.9.0、数据库元数据生命周期和配对授权码格式统一更新。
- 同步版本标识、发布工具与部署文档。Server 发布目标仍为 Linux AMD64 GNU，管理 API 为 `/api/v2`，Schema revision 为 7。

本次前端变更已通过 Chromium、Firefox 的配置编辑、跨分类校验与保存、移动端布局和配置区域无障碍验收。
