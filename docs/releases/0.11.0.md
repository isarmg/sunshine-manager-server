# Sunshine Manager Server 0.11.0

- 管理协议升级为唯一的 `sunshine-management/2`；旧协议和缺少完整能力描述的 Client 会被拒绝。
- Client 注册、身份检查与 WebSocket 入口升级为唯一的 `/sunshine-client/v2/*`，不保留 v1 路由；管理端升级到 Foundation 0.8.2 的登录与稳定 CSRF 合同。
- 增加应用列表、新建、编辑、删除、关闭当前应用及受限 PNG 封面上传。应用写入使用列表修订与内容引用，避免 Sunshine 排序后索引指向其他应用。
- 增加 Moonlight PIN、已配对客户端启停与取消配对；Manager 配对和 Moonlight 配对继续使用不同身份模型。
- 增加有界、分页、客户端脱敏的 Sunshine 日志，以及 API/认证/版本/服务诊断和虚拟输入驱动状态。
- 增加显示持久状态与 Portal token 维护，以及 Client 固定服务适配器的启动、停止、重启和状态核对。
- 配置表扩展为统一的版本、平台、类型、范围与前置条件定义；网络监听、凭据、证书、任意文件路径和通用 Shell 仍不开放。
- Web 按 Client 实际能力展示功能，所有危险操作保留管理员确认、15 分钟派发期限、持久幂等身份和 Foundation 操作审计。

此版本固定适配 Sunshine `v2026.914.233613`。Server、Client 和协议不提供旧版本或旧协议回退。
