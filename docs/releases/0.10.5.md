# Sunshine Manager Server 0.10.5

Sunshine compatibility is now an explicit allowlist rather than one exact historical build. The Server accepts both verified stable releases `2026.516.143833` and `2026.906.222525` in Client hello messages and configuration snapshots, while continuing to reject unverified prerelease or malformed versions.

This release keeps protocol revision 1 and does not change stored data. Clients must still report the Sunshine version they actually observed.
