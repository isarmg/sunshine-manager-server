# sunshine-manager-server 0.11.11

- 实例「日志」页默认显示服务器本地当天的全部 Manager 操作记录，可按日期选择其他日并手动刷新。日期按操作创建时间及服务器本地午夜划分，显示创建时间和 UTC 偏移；同一时刻的记录按操作 ID 稳定排序。
- 日志查询只返回当前管理员的操作内容；详情页仍用最新 50 条结果更新状态，实例的阻塞任务总数包含所有管理员。单次完整日志读取的 Web 预算为 64 MiB、120 秒，超出时显示错误。详情页的 Sunshine 原始诊断日志保留字节游标分页。
- 更换实例授权码会撤销旧设备凭据并终结旧授权下尚未执行的任务；已领取但未确认的任务保留为 unknown，供管理员核对实际设备状态。任务日志显示受控状态原因。
- Client 连接的终止性 401 带明确设备凭据拒绝标识；其他入口错误维持可重试语义。
- 数据库结构身份仍为 0.10.1 / Schema 7，管理协议仍为 sunshine-management/2。

## 验证

Rust 测试、严格 Clippy、Web 生产构建和 Chromium、Firefox 浏览器验收通过。日志验收覆盖大量记录、较大响应、浏览器与服务器时区差异及夏令时边界。
