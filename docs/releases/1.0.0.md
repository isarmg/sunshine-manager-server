# xscs 1.0.0

[发行页](https://github.com/isarmg/xscs/releases/tag/v1.0.0)提供 Linux x86_64 GNU 归档与同名 `.sha256`。包内包含服务二进制、内嵌管理 Web 的资源清单、systemd unit 和部署说明。

## 本版功能

Sunshine 实例、配置、应用、Moonlight PIN、日志/诊断、维护和固定平台服务管理。通信 xscs-management/1，业务任务 xscs-task/1，数据库结构 revision 1。

## 部署与验证

从[安装手册](../operations.md)开始。实际源码身份由归档的 manifest 和 binary identity 给出；main 的后续提交不自动改变已发布资产。

构建与测试分层见[开发指南](../development.md)，产品范围见[功能说明](../feature-inventory-and-tradeoffs.md)。浏览器或协议夹具验证覆盖对应软件行为，真实设备、驱动与串流表现需在目标主机验证。
