# Sunshine Manager Server 0.10.6

This patch republishes the current stable-Sunshine compatibility baseline under a new immutable version. The Server continues to accept the verified stable Sunshine builds `2026.516.143833` and `2026.906.222525` while rejecting malformed and unverified prerelease versions.

Protocol revision 1 and stored data are unchanged from 0.10.5. The Linux release archive is rebuilt and bound to the new tagged source identity.
