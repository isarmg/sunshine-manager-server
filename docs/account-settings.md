# 修改当前账号

登录管理 Web 后，点击顶部菜单栏最右侧的账号图标，输入账号名称和当前密码。
需要修改密码时填写并确认新密码；留空则保留密码。保存成功后，所有当前账号会话均失效，
使用新账号信息重新登录。

账号名称是登录用户名。修改账号不会改变内部账号 ID、设备、配置或操作日志的归属。
系统只允许一个活动管理员，Web 入口只修改当前账号，不提供管理员目录或创建入口。

Server 在首次启动的空管理员表中创建 bootstrap 账号，然后只读校验管理员数量、活动状态、
规范用户名和密码哈希。多账号、非活动账号或非法记录会阻止启动；启动校验不选择、停用或改写账号。

会话活跃时间单调更新，并发请求可以按不同顺序完成。空闲到期、修改账号和显式注销均要求重新登录。
